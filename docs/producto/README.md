# Producto

Curro & Parné está en fase de prototipo / pre-MVP con Málaga como mercado inicial. V9.4.3 permite explorar la actividad del negocio, plazas, incidencias, cancelaciones y reemplazos. El estado del pago está separado de la finalización del servicio; el tiempo adicional es informativo.

El prototipo es una demostración local, no un sistema de producción ni una confirmación de transacciones reales.
